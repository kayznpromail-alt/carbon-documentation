Flashing Your Bios

⚠️ Warning: Incorrect BIOS flashing can damage your system. Proceed at your own risk. Ensure you have the correct BIOS version and a stable power source. Ask support for help if needed!

Identifying your Motherboard & System Information

  1. Open System Information (type msinfo32 in searchbar)
  2. Find BaseBoard Product & Manufacturer
  3. Note Bios Version/Date
Note: If your system-information is inaccurate/Unsure, please go to your UEFI/BIOS settings & Verify the information.

FLASH PROCESS

  • Download a different Bios version than current (preferably downgrade).
  • Format USB to FAT32.
  • Flash Bios TWO TIMES, this is really important! No need for 2 different versions, just repeat the process twice.

BIOS Configuration

⚠️ Valorant Requirement: Do NOT disable Virtualization (VMX/SVM). Vanguard requires it for security features.

Enable TPM

  1. Enable TPM (Security Device Support) in BIOS Security Tab.
  2. If AMD CPU, enable fTPM. If Intel, enable PTT.

Secure Boot & CSM

  • Secure Boot: Enable and Restore Factory Boot Keys.
  • CSM: Disable CSM (failure to do so will cause serials to revert).

Confirm Correct Settings

  1. In Windows, run msinfo32. Check that Secure Boot State is On.
  2. Run tpm.msc. It must say "The TPM is present".
