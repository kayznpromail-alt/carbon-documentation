Disable Windows Defender

Disable Windows Defender Manually

1.
Select Start and type "Windows Security"
2.
Select the Windows Security app from the search results, go to Virus & threat protection, then under Virus & threat protection settings select Manage settings
3.
Switch Real-time protection to Off

Disable Windows Defender with dControl

Download dControl.zip (447KB)
1.
Download dControl above
2.
Unzip the files
3.
Run dControl.exe
4.
Disable Windows Defender
