Windows Reinstall

⚠️ Reinstalling Windows Will Result in a loss of data.

Install ISO

Download Windows 10 Media Creation Tool
1.
Download Media Creation Tool above, click Download Now
2.
Open Media Creation Tool
3.
Select "Create installation media (USB flash drive, DVD or ISO file) for another PC"
4.
Use the recommended options
5.
Select ISO file
6.
Select the directory
7.
After the Windows ISO Finishes, Download Rufus
Download Rufus 4.5
1.
Open Rufus and Select These Options. Press Select and go to the directory where you downloaded the ISO Device. Select your USB (8gb+).
2.
Select the Last Two Options
3.
Press OK and Wait For Rufus to complete the USB Format
4.
After Completed Drag this file inside of the USB

Your USB stick should look like this:

WiFi Users: Before Continuing If you are WiFi Make sure to download your WiFi Drivers onto the USB. You Can download the drivers from your motherboards website.

To Find your Motherboard do Win + R and type msinfo32, you should be able to find it under here:

Boot & Installation

1.
Hold SHIFT and click Restart
2.
Select Use a device and select your Flash Drive
3.
Select Windows 10 Pro
4.
Select I don't have a product key (If it doesn't show this don't worry)
5.
Select Custom: Install Windows only (advanced)

Disk Cleanup (Mandatory)

6.
Press SHIFT + F10
7.
Type diskpart into the CMD
8.
Type select disk # (# = for every disk number) and clean for every disk you have except your Flash Drive
Your Flash Drive is likely the last drive listed. DO NOT DELETE IT
9.
Close the CMD and click Refresh
10.
Select your main drive and click Next
11.
The installation process should start
