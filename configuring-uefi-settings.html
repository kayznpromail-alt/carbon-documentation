Configuring UEFI settings

Note: Virtualization settings (VMX/SVM/VT-d) must remain ENABLED for Valorant/Vanguard.

INTEL CPU's

  • 1. TPM: Advanced -> PCH-FW -> TPM Device Solution set to Enable Discrete Firmware/TPM. Also: Advanced -> Trusted Computing -> Security Device Support set to Enable.
  • 2. Armoury Crate: Tool -> ASUS Armoury Crate -> Download & Install ARMOURY CRATE app set to Disabled.
  • 3. Fast Boot: Boot -> Boot Configuration -> Fast Boot set to Disabled.
  • 4. Secure Boot: Boot -> Secure Boot -> OS Type set to Other OS.
  • 1. TPM: Settings -> Security -> Trusted Computing -> TPM Device Selection set to dTPM. Also: Security Device Support set to Enabled.
  • 2. MSI Driver Utility Installer: Settings -> Advanced -> MSI Driver Utility Installer set to Disabled.
  • 3. Fast Boot: Settings -> Boot -> Fast Boot set to Disabled.
  • 4. Secure Boot: Settings -> Security -> Secure Boot -> Secure Boot set to Enabled.
  • 1. TPM: Settings -> Miscellaneous -> Intel Platform Trust Technology (PTT) set to Enabled. Also: Trusted Computing -> Security Device Support set to Enabled.
  • 2. Gigabyte Utilities Downloader: Settings -> IO Ports -> Gigabyte Utilities Downloader Configuration -> Download & Install app set to Disabled.
  • 3. Fast Boot: Boot -> Fast Boot set to Disabled.
  • 4. Secure Boot: Boot -> Secure Boot -> Secure Boot Enable set to Enabled.
  • 1. Utility Installer: Disable any "Auto-Install" or "Driver Downloader" features.
  • 2. Fast Boot: Set to Disabled.
  • 3. TPM 2.0: Set to Enabled.

AMD CPU's

  • 1. AMD NX Mode: Advanced -> CPU Configuration -> NX Mode set to Disabled.
  • 2. TPM: Advanced -> AMD fTPM -> TPM Device Solution set to Discrete Firmware/TPM. Also: Trusted Computing -> Security Device Support set to Enabled.
  • 3. Armoury Crate: Tool -> ASUS Armoury Crate -> Download & Install ARMOURY CRATE app set to Disabled.
  • 4. Fast Boot: Boot -> Boot Configuration -> Fast Boot set to Disabled.
  • 5. Secure Boot: Boot -> Secure Boot -> OS Type set to Other OS.
  • 1. NX Mode: OC -> Advanced CPU Configuration -> NX Mode set to Disabled.
  • 2. TPM: Settings -> Security -> Trusted Computing -> AMD fTPM Switch set to Enabled.
  • 3. MSI Driver Utility Installer: Settings -> Advanced -> MSI Driver Utility Installer set to Disabled.
  • 4. Fast Boot: Settings -> Boot -> Fast Boot set to Disabled.
  • 5. Secure Boot: Settings -> Security -> Secure Boot -> Secure Boot set to Enabled.
  • 1. AMD NX Mode: Tweaker -> CPU Configuration -> NX Mode set to Disabled.
  • 2. TPM: Settings -> Miscellaneous -> Trusted Platform Module set to Enabled. Also: Trusted Computing -> Security Device Support set to Enabled.
  • 3. Gigabyte Utilities Downloader: Settings -> IO Ports -> Gigabyte Utilities Downloader Configuration -> Gigabyte Utilities Downloader set to Disabled.
  • 4. Fast Boot: Boot -> Fast Boot set to Disabled.
  • 5. Secure Boot: Boot -> Secure Boot -> Secure Boot Enable set to Enabled.
  • 1. NX Mode / No-Execute: Set to Disabled.
  • 2. Utility Installer: Disable any built-in driver downloaders.
  • 3. Fast Boot: Set to Disabled.
  • 4. fTPM: Set to Enabled.
SAVE YOUR CHANGES AND EXIT BIOS (F10 "Save and Exit").
